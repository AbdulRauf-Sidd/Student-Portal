# Student and Teacher Portal

Welcome to the Student and Teacher Portal project! This application provides a platform for students to access their grades and for teachers to assess them. Built using ASP.NET, this project includes a fully functional database with complex triggers to manage interactions between students and teachers.

## Features

- **Student Access**: Students can log in to view their grades across various subjects.
- **Teacher Assessment**: Teachers can input and manage student grades.
- **Database Integration**: A robust database with complex triggers to handle data consistency and integrity.
- **User Authentication**: Secure login system for both students and teachers.
- **Responsive Design**: Accessible on various devices for ease of use.

## Technologies Used

- **ASP.NET**: The core framework for building the web application.
- **C#**: The programming language used for backend logic.
- **SQL Server**: Database management system for storing and managing data.
- **Entity Framework**: ORM for database interactions.
- **Bootstrap**: For responsive and modern UI design.
